# Credentials Vault – Teilprojekt 2b: SSH — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Claude Code und Codex führen Befehle auf Zielen eines SSH-Eintrags aus (`ssh_exec`) und kopieren Dateien zwischen ihrem Server und dem Ziel (`ssh_put`, `ssh_get`), ohne Schlüssel oder Passwort je zu sehen — mit Freigabe nach dem Schalter des Eintrags, Host-Key-Sperre beim ersten Kontakt und Audit.

**Architecture:** Alle drei Werkzeuge laufen durch den Vermittlungskern `server/lib/vault/broker.js` aus 2a. Verbindungen gehen über die Engine als SFTP-Sitzung (`SessionType.SFTP`, `EngineSftpClient`); das Protokoll bekommt einen erwarteten Host-Key, eine Probe ohne Anmeldung und einen Modus ohne SFTP-Subsystem für reine Befehle, die Engine vergleicht den Host-Key in `sftp_session_thread` vor `outpost_ssh_auth`. Gemerkte Host-Keys liegen je (Eintrag, Ziel) in der neuen Tabelle `vault_ssh_host_keys`; Ziele sind Server aus der Serverliste und freie Hosts.

**Tech Stack:** Node.js ≥ 22 (Express 5, Sequelize, Joi, `node:test`), FlatBuffers (`yarn schema:generate`: flatc + esbuild), C-Engine mit libssh2 (CMake, `scripts/build-engine.sh`), React 19 + Vite, vitest/jsdom/Testing Library, lucide-react.

**Spec:** `docs/superpowers/specs/2026-10-11-vault-ssh-design.md` (inkl. mockingbird-Block Manifest-Revision 21 und preflight-Sicherheitsblock). Die Spec ist maßgeblich; dieser Plan argumentiert aus ihr. Grundlage: `docs/superpowers/specs/2026-10-10-vault-tokens-design.md` (2a, ausgeliefert in 0.1.11) und `docs/superpowers/specs/2026-10-09-vault-core-design.md` (Teilprojekt 1).

**Design:** `docs/design/manifest.yaml` (rev 21) — Design-System: `docs/design/design-system.md` — Artboards: `docs/design/mockups/index.html`

**Design Scope:** UI-VAULT, UI-VAULT-DIALOG, UI-VAULT-APPROVAL, UI-AGENT-ACCESS — zu bauen sind nur die Elemente aus `touched` der Revisionen 20 und 21 (UI-VAULT-DIALOG-SSH-SERVERS, -SSH-HOSTS, -SSH-SESSION, UI-VAULT-DETAIL-SSH-TARGETS, UI-VAULT-DETAIL-USAGE (geändert), UI-VAULT-APPROVAL-CARD (geändert), UI-VAULT-APPROVAL-EXEC, -COMMAND, -HOSTKEY, UI-AGENT-ACCESS-GUIDE (geändert)); alle übrigen Elemente dieser Screens sind Bestand und bleiben unverändert.

## Review Focus

1. **Ein Befehl gibt den privaten Schlüssel des Eintrags aus (`cat ~/.ssh/id_ed25519` auf einem Ziel, auf dem derselbe Schlüssel liegt).** Erwartet: jede Schlüsselzeile ab 16 Zeichen als `••••`, die Rahmenzeilen bleiben. → Test in Task 5.
2. **Die 64-KB-Grenze schneidet mitten in ein wiederholtes Passwort.** Erwartet: kein Anfang des Passworts bleibt stehen (`truncateAndRedact`). → Test in Task 5.
3. **Der Nutzer vergisst einen Host-Key, während eine alte Sitzungsfreigabe für denselben Fingerabdruck noch besteht.** Erwartet: trotzdem eine Karte mit „Neues Ziel“ (`skipSessionGrant`). → Test in Task 5.
4. **Jemand mit Bearbeitungsrecht am Server-Eintrag ändert dessen IP auf einen eigenen Rechner.** Erwartet: der gemerkte Key bleibt, die Engine meldet `HostKeyMismatch`, keine Anmeldung, Toast. → Test in Task 5 (Engine-Double) und Live-Reihe in Task 9.
5. **`ssh_put` auf ein Ziel, dessen Zielordner einem anderen Benutzer gehört und in dem bereits eine Datei mit dem Temp-Namen liegt.** Erwartet: zufälliger Temp-Name je Aufruf, kein Schreiben durch einen fremden Symlink, Temp-Datei 0600. → Test in Task 7.

## Abweichungen und Ergänzungen zur Spec

Beim Lesen des Codes gefunden; im Plan so umgesetzt, beim Review bitte bestätigen:

1. **Generierte Schema-Dateien sind gitignored** (`**/generated`): Task 2 und jeder spätere Test-Lauf erzeugen sie mit `yarn schema:generate`; CI tut das schon heute.
2. **Engine-Build nur als Docker-Image:** lokal fehlen cmake, flatcc und libssh2-Header. Task 1 baut `Dockerfile.engine` auf dem NAS (Image `outpost-engine:vault-ssh`), Task 9 nutzt es für die Live-Reihe.
3. **Engine-Felder an der Sitzung:** `expected_host_key`, `probe_host_key` und `exec_only` liegen in `outpost_session_t` (`engine/src/core/session.h`), nicht in den Verbindungsparametern.
4. **Zeitablauf:** Die Engine hängt bei abgelaufenem Befehl weiter „[command timed out after N seconds]“ an stderr an (Datei-Browser und KI-Assistent brauchen es). `ssh_exec` lässt den Text stehen; die Kopfzeile „exit 124 (timed out after n s)“ kommt aus `timedOut`.
5. **`GET /api/vault/items/:id` ist neu**, und `hostKeys` steht auch in der Liste; die Detailansicht braucht keine eigene Anfrage. `/entries/list` liefert zusätzlich `port` (Task 3, Step 9a), damit Server-Ziele als `benutzer@host:port` erscheinen.
6. **Owner-Abfrage beim SFTP-`stat`:** `handle_stat` in `engine/src/net/sftp.c` ruft für Eigentümer und Gruppe `stat -c '%U:%G' <pfad>` als Shell-Zeile auf, mit `shell_escape_path` (einfache Anführungszeichen, `'` als `'\''`). Da `ssh_put`/`ssh_get` nur absolute Pfade oder `~/` (nach Auflösung absolut) zulassen, kann ein Pfad weder aus den Anführungszeichen ausbrechen noch als Option gelesen werden. Entscheidung: ausreichend für SEC-INJECT-01; kein Umbau der Engine in 2b. Task 9 Step 5 prüft diese Stelle mit.
7. **Rechte von Dateien:** `EngineSftpClient#chmod` (SFTP SETSTAT) gibt es schon; `WriteBegin` legt Dateien mit 0644 und ohne `O_EXCL` an — der zufällige Temp-Name ist deshalb der Schutz gegen einen vorab angelegten Symlink, danach `chmod 0600` vor dem Schreiben des Inhalts.
8. **`USAGE_FIELDS` je Typ:** `hosts` darf nicht global in `USAGE_FIELDS` (der Hosts-Feld des API-Keys verschwände aus dem Dialog); Task 6 nutzt `usageFieldsOf(type)`.
9. **Karte:** der Befehl klappt ab 21 Zeilen ein und zeigt dann die ersten 20 (bei genau 20 gibt es nichts aufzuklappen); der Fingerabdruck steht auf der Karte vollständig (Guide), nur die Detailzeile kürzt ihn mit vollem Wert im `title`.
10. **`VAULT_NOTICE` wird im Client nicht für neue Abonnenten zwischengespeichert**, sonst zeigte ein später geöffneter Tab den Toast erneut.
11. **Schwärzung des ganzen Schlüssels:** erscheint der Schlüssel vollständig in der Ausgabe, ersetzt die Variante „ganzer Schlüssel“ ihn samt Rahmenzeilen durch ein `••••`; die Rahmenzeilen bleiben nur bei teilweiser Ausgabe (`head`, `grep`) stehen.
12. **`<kind>`-Texte** in `vault.ssh_failed` sind englisch wie alle Werkzeugmeldungen: `connection`, `timeout`, `login refused`, `engine not connected`, `SFTP not available`.
13. **Nebenwirkung von `username` im Stempel:** ändert sich der Benutzer eines Login-Eintrags bei offener Karte von `browser_fill_credential`, endet der Aufruf mit dessen bestehender Meldung `vault.origin_mismatch` (Bestandsverhalten jenes Werkzeugs nach dem Neuladen).

Zur Form: Die drei neuen `SessionOpen`-Felder landen als eigene Felder in `outpost_session_t` statt als `ConnectionParam`. So kann kein Verbindungsparameter eines Eintrags (`params` stammt aus Eintrags-Konfigurationen) eine Erwartung überschreiben oder eine Probe auslösen, und `outpost_sm_create` setzt sie per `memset` auf leer/`false` — ohne die Felder verhält sich jede Sitzung wie heute. Die Probe öffnet keine Datenverbindung: der Server wartet bei ihr nicht darauf (Spec „Sitzung zum Ziel“), eine geöffnete bliebe bis zum Ende des Threads hängen. Alle anderen SFTP-Sitzungen öffnen sie wie heute vor dem Handshake. Ein fehlender SHA256-Hash gilt bei gesetzter Erwartung als Abweichung (fail closed) und bei der Probe als Verbindungsfehler; bei einer Sitzung ohne Erwartung (Datei-Browser) ändert er nichts. SEC-SECRET-01: Die Engine protokolliert nur Fingerabdrücke, nie Parameter.

```c
static const char* host_key_algorithm(int type) {
    switch (type) {
        case LIBSSH2_HOSTKEY_TYPE_RSA:       return "ssh-rsa";
        case LIBSSH2_HOSTKEY_TYPE_DSS:       return "ssh-dss";
        case LIBSSH2_HOSTKEY_TYPE_ECDSA_256: return "ecdsa-sha2-nistp256";
        case LIBSSH2_HOSTKEY_TYPE_ECDSA_384: return "ecdsa-sha2-nistp384";
        case LIBSSH2_HOSTKEY_TYPE_ECDSA_521: return "ecdsa-sha2-nistp521";

        default:                             return "";
    }
}

static bool read_host_key(LIBSSH2_SESSION* ssh, sftp_host_key_t* out) {
    size_t len = 0;
    int type = LIBSSH2_HOSTKEY_TYPE_UNKNOWN;
    out->algorithm[0] = '\0';
    out->fingerprint[0] = '\0';

    if (libssh2_session_hostkey(ssh, &len, &type))
        snprintf(out->algorithm, sizeof(out->algorithm), "%s", host_key_algorithm(type));

    const unsigned char* hash = (const unsigned char*)
        libssh2_hostkey_hash(ssh, LIBSSH2_HOSTKEY_HASH_SHA256);
    if (!hash) return false;

    unsigned char b64[48];
    int n = EVP_EncodeBlock(b64, hash, 32);
    while (n > 0 && b64[n - 1] == '=') b64[--n] = '\0';
    snprintf(out->fingerprint, sizeof(out->fingerprint), "SHA256:%s", (const char*)b64);
    return true;
}
```

```c
static void* sftp_session_thread(void* arg) {
    sftp_thread_args_t* args = (sftp_thread_args_t*)arg;
    outpost_session_t* session = args->session;
    outpost_control_plane_t* cp = args->cp;
    int data_fd = -1;
    int ssh_sock = -1;
    LIBSSH2_SESSION* ssh = NULL;
    LIBSSH2_SFTP* sftp = NULL;
    jump_chain_t jump_chain = {0};
    sftp_host_key_t host_key = {0};

    session->state = SESSION_STATE_CONNECTING;

    const char* username   = outpost_session_get_param(session, "username");
    const char* password   = outpost_session_get_param(session, "password");
    const char* priv_key   = outpost_session_get_param(session, "privateKey");
    const char* passphrase = outpost_session_get_param(session, "passphrase");

    if (!username || strlen(username) == 0) {
        LOG_ERROR("SFTP session %s: missing username", session->session_id);
        outpost_cp_send_session_result(cp, session->session_id, false,
                                       "Missing username", NULL);
        goto cleanup;
    }

    jump_host_t jump_hosts[MAX_JUMP_HOSTS];
    int jump_count = outpost_extract_jump_hosts(session, jump_hosts, MAX_JUMP_HOSTS);

    LOG_INFO("SFTP session %s: connecting to %s:%u as %s (jump_hosts=%d, probe=%d, exec_only=%d)",
             session->session_id, session->host, session->port, username, jump_count,
             session->probe_host_key, session->exec_only);

    if (!session->probe_host_key) {
        data_fd = outpost_cp_open_data_connection(cp, session->session_id);
        if (data_fd < 0) {
            outpost_cp_send_session_result(cp, session->session_id, false,
                                           "Failed to open data connection", NULL);
            goto cleanup;
        }
    }

    if (outpost_ssh_setup_with_jumphosts(session->host, session->port,
            jump_hosts, jump_count, &ssh_sock, &ssh, &jump_chain) != 0) {
        outpost_cp_send_session_result(cp, session->session_id, false,
                                       "Failed to connect to SSH host", NULL);
        goto cleanup;
    }

    bool have_key = read_host_key(ssh, &host_key);

    // Without a hash there is no proof of identity: an expectation then counts as a mismatch.
    if (session->expected_host_key[0] != '\0' &&
        (!have_key || strcmp(session->expected_host_key, host_key.fingerprint) != 0)) {
        LOG_WARN("SFTP session %s: host key mismatch (expected %s, got %s)",
                 session->session_id, session->expected_host_key,
                 have_key ? host_key.fingerprint : "none");
        outpost_cp_send_session_result_ex(cp, session->session_id, false,
            "Host key mismatch", NULL, Outpost_ControlPlane_ErrorCode_HostKeyMismatch,
            host_key.algorithm, host_key.fingerprint);
        goto cleanup;
    }

    if (session->probe_host_key) {
        if (have_key)
            outpost_cp_send_session_result_ex(cp, session->session_id, true, NULL, NULL,
                Outpost_ControlPlane_ErrorCode_None, host_key.algorithm, host_key.fingerprint);
        else
            outpost_cp_send_session_result(cp, session->session_id, false,
                                           "Failed to read host key", NULL);
        goto cleanup;
    }

    if (outpost_ssh_auth(ssh, username, password, priv_key, passphrase) != 0) {
        outpost_cp_send_session_result_ex(cp, session->session_id, false,
            "SSH authentication failed", NULL, Outpost_ControlPlane_ErrorCode_AuthFailed,
            host_key.algorithm, host_key.fingerprint);
        goto cleanup;
    }

    LOG_DEBUG("SFTP session %s: authenticated", session->session_id);

    sftp = libssh2_sftp_init(ssh);
    if (!sftp) {
        char* errmsg = NULL;
        libssh2_session_last_error(ssh, &errmsg, NULL, 0);
        LOG_WARN("SFTP session %s: failed to open SFTP: %s",
                 session->session_id, errmsg ? errmsg : "unknown");
        if (!session->exec_only) {
            outpost_cp_send_session_result_ex(cp, session->session_id, false,
                "SFTP not available", NULL, Outpost_ControlPlane_ErrorCode_ConnectionFailed,
                host_key.algorithm, host_key.fingerprint);
            goto cleanup;
        }
    }

    session->state = SESSION_STATE_ACTIVE;
    outpost_cp_send_session_result_ex(cp, session->session_id, true, NULL, NULL,
        Outpost_ControlPlane_ErrorCode_None, host_key.algorithm, host_key.fingerprint);

    if (fp_send_ready(data_fd) != 0) {
        LOG_ERROR("SFTP session %s: failed to send Ready", session->session_id);
        goto cleanup;
    }

    LOG_INFO("SFTP session %s active (target=%s:%u, user=%s, sftp=%s)",
             session->session_id, session->host, session->port, username,
             sftp ? "yes" : "no");

    sftp_request_loop(session, sftp, ssh, data_fd);

    LOG_INFO("SFTP session %s ending", session->session_id);

cleanup:
    if (sftp) libssh2_sftp_shutdown(sftp);
    outpost_ssh_full_cleanup(ssh, NULL, ssh_sock, &jump_chain, "Session ended");
    if (data_fd >= 0)
        close(data_fd);

    char sid[MAX_SESSION_ID_LEN];
    snprintf(sid, sizeof(sid), "%s", session->session_id);
    outpost_cp_send_session_closed(cp, sid, "session ended");
    outpost_sm_finish(&g_session_manager, sid);

    free(args);
    return NULL;
}
```

```js
const DEFAULT_PORT = 22;
const HOSTNAME = /^(?=.{1,253}$)[a-z0-9](?:[a-z0-9-]{0,61}[a-z0-9])?(?:\.[a-z0-9](?:[a-z0-9-]{0,61}[a-z0-9])?)*$/;

const normalizeHost = (text) => {
    const match = typeof text === "string" ? HOST_PORT.exec(text.trim().toLowerCase()) : null;
    if (!match) return null;
    const [, host, portText] = match;
    const port = portText === undefined ? DEFAULT_PORT : Number(portText);
    if (port < 1 || port > 65535) return null;
    if (host.startsWith("[") ? !net.isIPv6(host.slice(1, -1)) : !HOSTNAME.test(host)) return null;
    return port === DEFAULT_PORT ? host : `${host}:${port}`;
};

const targetRefsOf = (item) => [
    ...(item.fields?.servers ?? []).map((id) => `server:${id}`),
    ...(item.fields?.hosts ?? []).map((host) => `host:${host}`),
];

// Only the canonical spelling targetRefsOf produces; the host comes without IPv6 brackets, as the engine connects to it.
const parseTargetRef = (ref) => {
    if (typeof ref !== "string") return null;
    const server = /^server:([1-9][0-9]{0,9})$/.exec(ref);
    if (server) return { kind: "server", entryId: Number(server[1]) };
    const text = ref.startsWith("host:") ? ref.slice("host:".length) : null;
    if (text === null || normalizeHost(text) !== text) return null;
    const [, host, port] = HOST_PORT.exec(text);
    return { kind: "host", host: host.replace(/^\[(.*)\]$/, "$1"), port: port ? Number(port) : DEFAULT_PORT };
};

    return row

        : null;
};

// A key pinned meanwhile by another call stays; the caller compares the returned fingerprint with its own.
const pinKey = async ({ itemId, ref, algorithm, fingerprint, accountId, transaction }) => {
    try {
        await VaultSshHostKey.create({

        }, { transaction });
    } catch (error) {
        if (error.name !== "SequelizeUniqueConstraintError") throw error;
    }
    return pinnedKey(itemId, ref, { transaction });
};
```

```js
const KIND = Object.freeze({
    CONNECTION: "connection", TIMEOUT: "timeout", LOGIN: "login refused", ENGINE: "engine not connected", SFTP: "SFTP not available",
});

const unavailable = () => new VaultError(VaultErrorCode.TARGET_UNAVAILABLE);
const newSessionId = () => `vault-ssh-${randomUUID()}`;
const closeEngineSession = (sessionId, target) => {
    try {
        controlPlane.closeSession(sessionId, target.engineId);
    } catch {}
};

const sshFailed = (target, kind) => new VaultError(VaultErrorCode.SSH_FAILED,
    VaultErrorMessage[VaultErrorCode.SSH_FAILED].replace("<target>", target.ref).replace("<kind>", kind)
    + (kind === KIND.LOGIN ? " Ask the user to check the entry's user and key." : ""));

const hostKeyChanged = (ref, expected, actual) => new VaultError(VaultErrorCode.HOST_KEY_CHANGED,
    VaultErrorMessage[VaultErrorCode.HOST_KEY_CHANGED].replace("<target>", ref).replace("<alt>", expected).replace("<neu>", actual),
    { expected, actual });

// Engine errors only ever leave as one of these kinds: their text may name hosts behind jump hosts or libssh2 details.
const sshFailure = (err, target, signal = null) => {
    if (err instanceof VaultError) return err;
    if (signal?.aborted) return new VaultError(VaultErrorCode.CLIENT_GONE);
    const message = String(err?.message ?? "");
    if (err?.errorCode === "AuthFailed") return sshFailed(target, KIND.LOGIN);
    if (message.includes("SFTP not available")) return sshFailed(target, KIND.SFTP);
    if (message === "No engine connected") return sshFailed(target, KIND.ENGINE);
    if (err?.errorCode === "Timeout" || /timeout/i.test(message)) return sshFailed(target, KIND.TIMEOUT);
    return sshFailed(target, KIND.CONNECTION);
};

const resolveTarget = async (item, ref, ctx, { withJumpHosts = true } = {}) => {
    const parsed = typeof ref === "string" ? parseTargetRef(ref) : null;
    if (!parsed || !targetRefsOf(item).includes(ref)) throw new VaultError(VaultErrorCode.TARGET_NOT_ALLOWED);
    if (parsed.kind === "host") {
        if (!(await hasAccountPermission(ctx.accountId, Permission.CONNECT_DIRECT))) throw unavailable();
        return { ref, kind: "host", name: ref.slice("host:".length), host: parsed.host, port: parsed.port ?? 22, jumpHosts: [], engineId: null };
    }
    const entry = await Entry.findByPk(parsed.entryId);
    if (!entry || entry.type !== "server" || entry.config?.protocol !== "ssh" || !entry.config?.ip) throw unavailable();
    if (item.organizationId && (await resolveEntryScope(entry)).organizationId !== item.organizationId) throw unavailable();
    if (!(await validateEntryAccess(ctx.accountId, entry, undefined, Permission.CONNECT_SSH)).valid) throw unavailable();
    const jumpHosts = withJumpHosts ? await resolveJumpHosts(entry).catch(() => { throw unavailable(); }) : [];
    return {
        ref, kind: "server", name: entry.name, host: entry.config.ip, port: Number(entry.config.port) || 22,
        jumpHosts, engineId: entry.config.engineId ?? null,
    };
};

const assertEngine = (target) => {
    const connected = target.engineId ? controlPlane.getEngineInfo(target.engineId) !== null : controlPlane.hasEngine();
    if (!connected) throw sshFailed(target, KIND.ENGINE);
};

// Only the username: sftp_session_thread stops without one, and nothing secret may reach a target before its key is confirmed.
const probeHostKey = async (target, username) => {
    const sessionId = newSessionId();
    try {
        const result = await controlPlane.openSession(sessionId, SessionType.SFTP, target.host, target.port, { username },
            target.jumpHosts, target.engineId, { probeHostKey: true });
        if (!result?.hostKey?.fingerprint) throw new Error("No host key");
        return { algorithm: result.hostKey.algorithm, fingerprint: result.hostKey.fingerprint };
    } catch (err) {
        throw sshFailure(err, target);
    } finally {
        closeEngineSession(sessionId, target);
    }
};

const openTargetSession = async (target, params, { expectedHostKey = null, execOnly = false, signal = null } = {}) => {
    const sessionId = newSessionId();
    let client = null;
    let ended = false;
    const close = () => {
        client?.close();
        if (ended) return;
        ended = true;
        signal?.removeEventListener("abort", close);
        closeEngineSession(sessionId, target);
    };
    signal?.addEventListener("abort", close, { once: true });
    try {
        if (signal?.aborted) throw new VaultError(VaultErrorCode.CLIENT_GONE);
        const socket = await openEngineSession(sessionId, SessionType.SFTP, target.host, target.port, params,
            target.jumpHosts, target.engineId, { expectedHostKey, execOnly });
        client = new EngineSftpClient(socket);
        await client.waitForReady();
        if (signal?.aborted) throw new VaultError(VaultErrorCode.CLIENT_GONE);
        return { client, close };
    } catch (err) {
        close();
        if (err?.errorCode === "HostKeyMismatch") throw hostKeyChanged(target.ref, expectedHostKey, err.hostKey?.fingerprint ?? "none");
        throw sshFailure(err, target, signal);
    }
};

const sshParams = (item, { privateKey = null, passphrase = null, password = null }) => ({
    username: item.fields?.username ?? "",
    ...(password && { password }),
    ...(privateKey && { privateKey }),
    ...(passphrase && { passphrase }),
});
```

```js
    const running = new Map();
    return {
        rate: createRateLimit({ windowMs: 60 * 1000, limit: 30 }),
        enter: (ctx) => {
            const key = callerKey(ctx);
            const count = running.get(key) ?? 0;
            if (count >= MAX_RUNNING) throw new VaultError(VaultErrorCode.BUSY);
            running.set(key, count + 1);
            return key;
        },
        leave: (key) => {
            const count = (running.get(key) ?? 1) - 1;
            if (count > 0) running.set(key, count);
            else running.delete(key);
        },
    };
};

// A cat of the key prints it line by line, and a partial one never matches the key as a whole.
const keyLines = (key) => key.split(/\r?\n/).map((line) => line.trim()).filter((line) => line.length >= MIN_KEY_LINE && !KEY_FRAME.test(line));
const variantsFor = ({ password, passphrase, privateKey }) =>
    [password, passphrase, privateKey, ...(privateKey ? keyLines(privateKey) : [])].filter(Boolean).flatMap(variantsOf);

const readSecrets = async (itemId) => {
    const privateKey = await readSecret(itemId, "privateKey");
    const passphrase = await readSecret(itemId, "passphrase");
    const password = await readSecret(itemId, "password");
    if (!privateKey && !password) throw new VaultError(VaultErrorCode.NO_SECRET);
    return { privateKey, passphrase, password };
};

const hostLabel = (host) => (host.includes(":") ? `[${host}]` : host);

const sshUse = async (ctx, { broker, sshLimits, audit }, {
    item: itemArg, target: targetArg, tool, access, card = () => ({}), validate = () => {}, prepare = async () => {}, act, auditExtra = {},
}) => {
    const state = { target: null, pinned: null, probed: null };
    const hostKey = () => state.pinned ?? state.probed;
    let entered = null;

    const record = (item, action, details) => audit({
        accountId: ctx.accountId, organizationId: item.organizationId ?? null, action, resource: RESOURCE_TYPES.VAULT, resourceId: item.id,
        details: { item: itemRef(item), tool, keyId: ctx.keyId ?? null, target: state.target.ref, ...details },
        ipAddress: ctx.ipAddress ?? null, userAgent: ctx.userAgent ?? null,
    });

    const confirmHostKey = async (item) => {
        const expected = hostKey();
        const current = await pinnedKey(item.id, state.target.ref);
        if (!current && !state.probed) throw new VaultError(VaultErrorCode.APPROVAL_STALE);
        const stored = current ?? (await pinKey({ itemId: item.id, ref: state.target.ref, ...state.probed, accountId: ctx.accountId }));
        if (stored.fingerprint !== expected.fingerprint) throw hostKeyChanged(state.target.ref, expected.fingerprint, stored.fingerprint);
        if (!current) await record(item, AUDIT_ACTIONS.VAULT_SSH_HOST_KEY_PINNED, { algorithm: stored.algorithm, fingerprint: stored.fingerprint });
        state.pinned = stored;
    };

    const reportMismatch = async (item, { expected, actual }) => {
        await record(item, AUDIT_ACTIONS.VAULT_SSH_HOST_KEY_MISMATCH, { expected, actual });
        stateBroadcaster.push([ctx.accountId], stateBroadcaster.STATE_TYPES.VAULT_NOTICE,
            { kind: "ssh_host_key_mismatch", item: itemRef(item), target: state.target.ref, name: state.target.name });
    };

    try {
        const { result } = await broker.use({
            ctx, itemRef: itemArg, tool, access, lazySecret: true, auditExtra,
            target: (item) => (state.target
                ? `${state.target.name} · ${item.fields?.username ?? ""}@${hostLabel(state.target.host)}:${state.target.port}`
                : null),
            scope: () => `${access}#${state.target.ref}#${hostKey().fingerprint}`,
            allowSession: (item) => item.fields?.allowSession === true,
            forceApproval: () => state.probed !== null,
            card: (item) => ({
                sshTarget: { ref: state.target.ref, name: state.target.name, user: item.fields?.username ?? null, host: state.target.host, port: state.target.port },
                ...card(item),
                ...(state.probed && { hostKey: { ...state.probed, new: true } }),
            }),
            check: async (item, { phase }) => {
                if (item.type !== "ssh")
                    throw new VaultError(VaultErrorCode.WRONG_TYPE, `${itemRef(item)} is a ${item.type} entry; ${tool} uses SSH entries only.`);
                if (targetRefsOf(item).length === 0) throw new VaultError(VaultErrorCode.NO_TARGETS);
                state.target = await resolveTarget(item, targetArg, ctx);
                Object.assign(auditExtra, { target: state.target.ref, host: state.target.host, port: state.target.port, user: item.fields?.username ?? null });
                await validate(item);
                if (phase === "after") return confirmHostKey(item);
                sshLimits.rate(ctx);
                assertEngine(state.target);
                await prepare(item, state.target);
                state.pinned = await pinnedKey(item.id, state.target.ref);
                if (!state.pinned) state.probed = await probeHostKey(state.target, item.fields?.username);
            },
            act: async (_unused, item) => {
                // Taken only now: a call waiting for the user's approval does not hold one of the 2 slots.
                entered = sshLimits.enter(ctx);
                try {
                    const secrets = await readSecrets(item.id);
                    const params = sshParams(item, secrets);
                    const open = (options = {}) => openTargetSession(state.target, params, { ...options, expectedHostKey: hostKey().fingerprint });
                    return await act({ item, target: state.target, open, variants: variantsFor(secrets) });
                } catch (err) {
                    if (err?.code === VaultErrorCode.HOST_KEY_CHANGED && err.details?.actual) await reportMismatch(item, err.details);
                    throw sshFailure(err, state.target, ctx.signal);
                }
            },
        });
        return result;
    } finally {
        if (entered) sshLimits.leave(entered);
    }
};

module.exports = { createSshLimits, sshUse };
```

```js
const MAX_TIMEOUT_SEC = 600;

const def = {
    name: NAME,
    description: "Run a shell command on one of the targets of a vault SSH entry. Outpost logs in itself with the entry's user and key or password; you never see them. No terminal: interactive programs and sudo password prompts do not work — use an entry for the user you need. The user approves every call and sees the full command. Output: exit code, stdout and stderr, each cut at 64 KB; the entry's password and key are replaced by ••••.",
    inputSchema: {
        type: "object",
        properties: {
            item: { type: "string", description: "Entry id as vault_list shows it, e.g. web-deploy or org:3/ops" },
            target: { type: "string", description: "Target as vault_list shows it under targets, e.g. server:12 or host:nas.lan:2222" },
            command: { type: "string", description: "Shell command, at most 8 KB; runs as the entry's user without a terminal" },
            timeoutSec: { type: "integer", minimum: 1, maximum: MAX_TIMEOUT_SEC, description: "Seconds before Outpost stops the command, 1–600, default 60; the process on the target may keep running" },
        },
        required: ["item", "target", "command"],
    },
};

const textResult = (text) => ({ content: [{ type: "text", text }] });

const assertCommand = (command, timeoutSec) => {
    if (typeof command !== "string" || command.length === 0 || Buffer.byteLength(command) > COMMAND_LIMIT || command.includes("\0"))
        throw new VaultError(VaultErrorCode.BAD_COMMAND);
    if (!Number.isInteger(timeoutSec) || timeoutSec < 1 || timeoutSec > MAX_TIMEOUT_SEC) throw new VaultError(VaultErrorCode.BAD_TIMEOUT);
};

const format = (run, timeoutSec, variants) => {
    const stream = (text) => truncateAndRedact(text ?? "", OUTPUT_LIMIT, variants).text;
    const head = `exit ${run.exitCode}${run.timedOut ? ` (timed out after ${timeoutSec} s)` : ""}`;
    return [head, "--- stdout ---", stream(run.stdout), "--- stderr ---", stream(run.stderr)].join("\n");
};

const handler = (args, ctx, deps) => {
    const { command } = args;
    const timeoutSec = args.timeoutSec ?? DEFAULT_TIMEOUT_SEC;
    const details = { command: typeof command === "string" ? command.slice(0, AUDIT_COMMAND_LIMIT) : null };
    return sshUse(ctx, deps, {
        item: args.item, target: args.target, tool: NAME, access: "exec", auditExtra: details,
        validate: () => assertCommand(command, timeoutSec),
        card: () => ({ command }),
        act: async ({ open, variants }) => {
            details.command = redactSecretText(command, variants).slice(0, AUDIT_COMMAND_LIMIT);
            const session = await open({ execOnly: true, signal: ctx.signal });
            try {
                const run = await session.client.exec(command, timeoutSec * 1000);
                Object.assign(details, {
                    exitCode: run.exitCode, timedOut: run.timedOut === true,
                    bytes: Buffer.byteLength(run.stdout ?? "") + Buffer.byteLength(run.stderr ?? ""),
                });
                return textResult(format(run, timeoutSec, variants));
            } finally {
                session.close();
            }
        },
    });
};

module.exports = { def, handler, needsBrowser: false };
```

```js
export const usageFieldsOf = (type) => (type === "ssh" ? SSH_USAGE_FIELDS : USAGE_FIELDS);

const LIST_FIELDS = ["origins", "hosts", "fillOrigins"];

const HOSTNAME = /^[a-z0-9]([a-z0-9-]{0,61}[a-z0-9])?(\.[a-z0-9]([a-z0-9-]{0,61}[a-z0-9])?)*$/;

export const normalizeHost = (text) => {
    const match = /^(\[[0-9a-f:.]+\]|[^:[\]]+)(?::(\d{1,5}))?$/i.exec(text.trim());
    if (!match) return null;
    const host = match[1].toLowerCase();
    const port = match[2] === undefined ? 22 : Number(match[2]);
    if (port < 1 || port > 65535 || (!host.startsWith("[") && !HOSTNAME.test(host))) return null;
    return port === 22 ? host : `${host}:${port}`;
};
```

```js
        await to.writeFile(temp, Buffer.alloc(0));

                done(bytes > FILE_LIMIT ? withPath(VaultErrorCode.FILE_TOO_LARGE, names.source) : null, chunk);

            signal?.removeEventListener("abort", stop);

        },
        card: () => ({ file: { from: args.remotePath, to: args.localPath, bytes: null } }),
        act: async ({ open }) => {

            try {
                const sourcePath = await resolveHome(target.client, args.remotePath);

                });
                return textResult(`Copied ${details.bytes} bytes from ${args.remotePath} to ${args.localPath}.`);
            } finally {

                target.close();
            }
        },
    });
};
```
